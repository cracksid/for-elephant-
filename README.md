# Princess Day Wishes

A one-page animated Princess Day greeting. Tap or click anywhere to move to the next wish.
Music starts on the first tap (browsers block autoplay), and the button in the top-right corner mutes it.

## Files
- `index.html` — the whole site (wishes, animation, castle and music are all inside this one file)

## Deploy on Vercel
1. Import this repository in Vercel.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Click **Deploy**.
